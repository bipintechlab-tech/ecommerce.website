# 🛍️ ShopEasy - E-Commerce Website

A responsive e-commerce website built using HTML, CSS, and JavaScript.

## 🚀 Live Demo
[
(https://github.com/bipintechlab-tech/ecommerce.website/tree/main)

## 📌 Features

- Responsive design
- Product listing
- Product search
- Category filtering
- Add to cart
- Increase/decrease product quantity
- Shopping cart
- Total price calculation
- Local Storage
- Checkout functionality

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
